# Анализ и оптимизация — 2026-10-02

Исследованы Rust-код, TypeScript, серверный адаптер, зависимости и lock-файлы,
IPC-разрешения, конфигурации трёх ОС, нативные меню/диалоги, хранение настроек,
иконки, тестовые серверы, упаковка и GitHub Actions. Изменения сделаны поверх
существующего рабочего дерева; ранее подготовленные изменения сохранены.

## Измеренный результат

Две release-сборки на одном Mac arm64, с теми же версиями инструментов и
зависимостей, macOS-конфигурацией и ad-hoc подписью. Размеры — сумма байтов
реальных файлов, без округления файловой системой и без сжатия архива.

| Артефакт | До, байт | После, байт | Снижение |
| --- | ---: | ---: | ---: |
| Исполняемый файл macOS | 7 900 320 | 6 033 232 | 23,63% |
| Полный пакет `.app` | 7 951 581 | 6 095 341 | 23,34% |
| Все файлы локального WebView (`dist`) | 20 032 | 18 242 | 8,94% |

Встроенный серверный веб-клиент не входит в `dist`: его загружает системный
WebView напрямую. Размеры `node_modules`, Rust toolchain и `target` относятся
к среде разработки и не попадают в приложение. Пользовательские кэши не удалялись.

Результат можно воспроизвести:

```sh
npm run desktop:build -- --ci --config src-tauri/tauri.macos.conf.json --bundles app -- --locked
npm run size
```

Исходные JSON-замеры и контрольная `.app` сохранены локально в
`artifacts/optimization/`; этот каталог исключён из Git.
`npm run size` измеряет уже существующие файлы, поэтому перед сравнением нужна
свежая сборка. Цифры выше относятся только к macOS, а не к DEB/AppImage/MSI.

## Анализ по компонентам

| Компонент | Вывод и действие |
| --- | --- |
| Архитектура | Tauri и системный WebView уже подходят для лёгкого клиента. Сохранены прямые запросы к серверу, API/WebSocket и его собственный интерфейс. |
| Rust-зависимости | Все прямые зависимости используются. `reqwest` нужен для ошибок TLS/HTTP и проверки cookie-сессии, `rfd` — для нативных диалогов macOS/Windows, GTK/WebKit — для Linux. Замена библиотек не требовалась. |
| Сборка Rust/Tauri | Добавлен `opt-level = "s"`; сохранены thin LTO, strip и одна codegen unit. Отключена неиспользуемая динамическая модификация ACL. Включено удаление IPC-команд, не разрешённых статическими capabilities. |
| Фоновые задачи | Раньше после успеха/отмены оставались сетевые проверки и 15-секундные таймеры. Теперь цикл владеет каналом отмены; его завершение или удаление освобождает ожидающие задачи. Проверка транспорта и дедлайн используют одну задачу вместо двух. |
| Проверка авторизации | Сохранены переиспользование HTTP-клиента, системные TLS roots, ограничения редиректов, фильтрация cookie по origin/path/secure и общий дедлайн. Уже исполняющийся блокирующий вызов ОС для чтения cookie завершается самостоятельно. |
| Настройки | Повторное сохранение неизменившихся данных не сериализует JSON и не обращается к диску. Изменения записываются атомарно, ошибки допускают повтор; очистка старых URL с токенами сохранена. |
| Frontend | Используются обычные TypeScript/DOM и только Tauri API. Каталоги разделены на `ui`, `menu`, `native`: WebView импортирует только `ui`, не дублируя нативные переводы в JS. Все языки и тексты сохранены. |
| Серверная оболочка | До появления body нужен полный DOM observer; затем наблюдаются только непосредственные дочерние элементы body и замена body. После появления mount наблюдение прекращается. Вложенные изменения чужой страницы больше не будят адаптер. |
| Внешние ссылки | Отключён дублирующий скрипт opener, который пытался использовать запрещённый удалённому окну IPC. Ссылки обслуживают существующие Rust callbacks навигации и новых окон. |
| Меню, диалоги, сессия | Сохранены платформенные ветки, независимые GTK-меню, системные диалоги, browser profile, reset, горячие клавиши, zoom, закрытие и повторная активация. |
| Упаковка и CI | Сохранены все форматы пакетов и три платформенных job. Не сокращались функциональные проверки. Исправлены ссылки на удалённый ранее `assets/README.md`: атрибуция ведёт к существующим SVG и лицензии. |

Новые сетевые worker-функции вынесены в `connection.rs`, чтобы основной модуль
не превысил ограничение размера проектного аудитора. Это разделение обязанностей,
а не самостоятельное уменьшение бинарного файла.

## Сохранение поведения и границ доверия

Локальные capabilities и список команд AppManifest не расширены. Каждая команда
по-прежнему проверяет метку вызывающего окна; удалённый WebView не получает IPC.
Удаление недоступных обработчиков выполняет сборщик Tauri; вызовы нативных
Rust API для окон, меню и диалогов сохраняются. X11, D-Bus, сжатие ассетов и
Windows common controls включены явно. Panic unwinding оставлен включённым.

Отмена при успехе, Cancel, смене сервера, новом цикле reload и скачивании
использует один механизм. Идентификаторы попытки/цикла дополнительно защищают
от уже поставленных в очередь старых callbacks.

## Проверки

- `npm run ci:check`: 20 тестов релизных скриптов, 2 теста аудитора,
  ESLint, 21 frontend-тест, TypeScript и production-сборка — проходят.
- `npm run native:check` на macOS: rustfmt, Clippy с `-D warnings`,
  19 Rust-тестов — проходят. TCP-тестам требуется выход из песочницы.
- Проектный и vendored Tauri-аудит: 0 ошибок; 1 известное предупреждение
  из-за создания окон в Rust вместо статического `app.windows`.
- `npm run ci:workflows`: проходит после загрузки actionlint с проверкой SHA-256.
- Release `.app` собирается; `codesign --verify --deep --strict` проходит,
  исполняемый файл имеет архитектуру arm64.
- Новые регрессионные тесты проверяют завершение/замену/удаление рабочих циклов,
  отсутствие повторного файлового I/O, повтор после ошибки записи, очистку
  старого URL, отложенный mount, вложенные mount и замену body.

Нативная проверка GUI на macOS ограничена тайм-аутом Computer Use при выборе
точного пути новой `.app`. Работа её меню, диалогов, авторизации и системных
горячих клавиш в этом запуске не подтверждена. Установленный ранее экземпляр
приложения не заменялся. Developer ID/notarization и новый DMG не проверялись.

Linux: Ubuntu 22.04/x86_64 в Docker под эмуляцией на Apple Silicon. Проходят
frontend-проверки, rustfmt, Clippy, 19 Rust-тестов и отдельный GTK Save/Cancel.
Собраны DEB и AppImage. Полный нативный сценарий проходит
как на release-бинарном файле, так и после установки DEB в одноразовом контейнере:
авторизация/API/WebSocket, IPC denial, внешние ссылки через нативный launcher,
upload/download, clipboard, горячие клавиши, независимая прокрутка, resize/zoom,
reload, expiry/reset/retry, cookie после рестарта, network/403/TLS и отмена.
Отдельно проходят настройки/языки, обычные скачивания без WebDriver и
startup/authentication/Save/Cancel/content упакованного AppImage AppRun.

Первый общий Linux-запуск остановился на X11 wheel input. После добавления
ожидания фактического WebKit `:hover` полный сценарий проходит. Тест внешних
`_blank` ссылок использует доверенный клик WebDriver: программный `.click()`
может быть заблокирован WebKit до нативного callback. Финальные проверки
выполнены отдельными контейнерами на той же сборке; общий pipeline после этой
правки теста целиком не повторялся. Итоговые логи находятся в
`artifacts/optimization/linux-*-final.log`.

В контейнере сохраняются предупреждения GTK об accelerator group и отсутствующем
AT-SPI; соответствующие нативные сценарии проходят. Прямой FUSE/runtime запуск
AppImage на физическом x86_64, Wayland и Debian 12 в этом запуске не проверялись.
Windows-хоста нет: изменения требуют штатного CI и ручной проверки на Windows.

## Пределы измерения

Снижение размера пакета измерено. Сокращение фоновых задач и файловых записей
подтверждено кодом и регрессионными тестами. Сравнительные RSS, CPU, время запуска
и скорость реального сервера не измерялись: численные обещания по ним не делаются.
Профиль `s` может обменивать скорость отдельных вычислений на меньший код; для
этого клиента основная работа проходит в WebView и по сети, но отдельного
бенчмарка вычислительной нагрузки не проводилось.

Настройки сборки сверены с официальными источниками:
[Tauri: App Size](https://v2.tauri.app/concept/size/),
[Tauri: Capabilities](https://v2.tauri.app/security/capabilities/),
[Cargo: Profiles](https://doc.rust-lang.org/cargo/reference/profiles.html).
API opener и состав feature-флагов дополнительно проверены в исходниках
закреплённых crate-версий.
